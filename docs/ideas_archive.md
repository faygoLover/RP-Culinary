# Архив идей RP Culinary

Идеи, которые Alex убрал из планов. Не делать без отдельного решения.

## «Советская кухня» — отдельный аддон (убрано 29.10.2026)
Новые культуры (огурец, чеснок, перец, рожь, гречка, пшено, подсолнечник, горох и фасоль как растения), молочка (сметана, творог, кефир,
сливки), квас, компот, майонез, кетчуп — только вместе с блюдами, которые их требуют (борщ, щи, оливье, сырники, квас…). В сборке ни одно
блюдо их не просит.

## Порча продуктов (убрано 29.10.2026)
Сырое мясо и рыба портятся за RP-сутки, соленья и копчёности хранятся дольше. С порчей разделка шла бы с K = 1, без неё — K = 0.25
(`butchery_carcasses_2026-10-28.md` §5). Испорченное сейчас — только готовые гнилые предметы модов (группа «Испорченное»).
