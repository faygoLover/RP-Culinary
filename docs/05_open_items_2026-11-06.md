## 1. Что думал пользователь — проверено

### Сосиски из любого мяса — да, но цепочкой через фарш
- Любое мясо → мясорубка F&C → фарш. Фарш — один из трёх предметов по цвету вида, вид записан в NBT
  (`server/Processing.java:345–381`, `minceFor` — `:403`). Субпродукты дают «ливерный» фарш (`:366–370`).
- Фарш → мясорубка Butchery с насадкой: **4 фарша + кишки** (+ бутылка крови — кровяная) → сырая связка,
  состав и облик берутся от фарша (`mixin/ButcheryGrinderMixin.java`, коммит `73be4b0`). Подходит любой фарш
  из тега `#rpculinary:mince` (3 предмета).
- Сырое мясо **напрямую** в мясорубку Butchery не идёт: её мясной помол отменён (`ButcheryGrinderMixin.java:41–43`).
  Это по решению 29.10 («из фарша, без обрезков и не из сырой свинины»).
- Ограничения, которые видно по коду:
  - 4 фарша должны лежать одной стопкой (один слот), то есть с одинаковым составом. Разные виды сначала
    смешивают в миске F&C в «домашний» фарш.
  - Метки «ливерный» и «жирный» (`rpculinary:offal`, `rpculinary:fatty`) на связку **не переходят**: `Source.copy`
    копирует только состав и облик. Связка из ливерного фарша считается как обычное мясо того же вида.
  - Автотеста на сосиски нет. В GameTest 19/19 нет ни одного теста со словом sausage.

### Поваренные книги — да, есть (`c612806`, 03.11)
- Предметы: `item/CookbookItems.java` — `rpculinary:cookbook` (9 разделов через NBT: супы, выпечка, мясо, рыба,
  закуски, напитки, справочник мясника, заготовки, винокур) и личная `rpculinary:recipe_notebook`.
- Окно: `client/CookbookScreen.java`, данные — `assets/rpculinary/cookbook.json` (генерирует `tools/gen_cookbook.py`):
  база из 23 рецептов у каждого повара, 9 книг (325 рецептов), 15 сложных нарочно вне книг (`secret`).
- «Переписать» в личную книгу: `network/CookbookPacket.java`, навык и перк проверяет сервер.
- После этого: `58c068f`, `317cde2` (текст торта), версия 0.8.6 (`c326c9b`).
- **Каких новых рецептов в книгах нет:** тарелка сосисок `board/sausage_plate` (4 × `brewery:sausage`), связка
  в мясорубке Butchery (это не рецепт, а миксин, окно книги показать её не может), домашний фарш `bowl/home_mince`.
  Бульон, шкварки, половинка курицы, копчёный окорок и роллы в книгах есть.
