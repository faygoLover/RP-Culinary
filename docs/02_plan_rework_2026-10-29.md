## Блок 1. Датапак и теги (без кода)
Кладём в ресурсы RP Culinary (`data/…`), чтобы ехало с модом.
1. **Теги-равнозначности:** томат/лук FD = F&C (`forge:vegetables/tomato|onion`, `forge:seeds/tomato`); вся соль → `forge:salt` (кроме блока CS); фарш (3 предмета) → `rpculinary:mince`; сосиски → `rpculinary:sausage`.
2. **Убрать из тегов сырого мяса:** отрубы Butchery, большие куски, `candlelight:beef_tartare` (блюдо из фарша).
3. **Разделка Butchery (K = 0.25):** переписать `butchery:blocks/*_cut_N_drop`, `organs_drop_1..3`, `*_head_drop` под этапы из галереи (корова, свинья, овца/коза, курица, кролик, рыба, дичь). Органы — по весу туши; инсулин (желудок), адреналин (почки), нить для швов (кишки) — позже, в Медицине.
4. **Дроп мобов:** глобальный модификатор добычи — убрать ванильное мясо и окорок FD (нож); Alex's Mobs / Alex's Caves — вместо мяса крупный кусок (вес в NBT — блок 2). Туша — при любом убийстве, кроме игрока (`Only Cleavers Drop Carcasses = false` в конфиге Butchery, сервер и клиент).
5. **Рецепты (по вкладкам галереи):**
   - верстак → станции: «Блюда на верстаке», «Аналоги» (супы, хлеб, тосты, бургеры и сэндвичи на доске Refurbished, салаты в миске F&C, выпечка на плите/в духовке, соки через пресс Vinery, сыр, горячий шоколад, яичница с беконом: жаровня F&C и сковорода FD, праздничные блоки FD, починить ссылку `butchery:smoked_ham` → `farmersdelight:smoked_ham`);
   - новые рецепты «Без рецепта» (пиццы SCP:O в духовке Refurbished, хот-дог, тако, буррито, пончики, вафли, печенье, рисовое печенье, чипсы, консервы через кастрюлю + банку, водка на станции Brewery, корм для собак SA); перец в пицце → капуста/салат, неаполитанская + зелень;
   - бекон FD — только с доски из грудинки; F&C бекон → «Сало» (резать со свиного шпика); фарш — только мясорубка F&C; сосиски — мясорубка Butchery; сырая котлета (`farmersdelight:minced_beef`) — из фарша на доске; каменная соль → ступка Butchery → соль;
   - рыбные рецепты FD — 2–3 ломтика вместо одного (ломтик теперь 100 г).
6. **Скрыть дубли** (JEI + креатив через RP Core lock, рецепты убрать): `farmersdelight:ham`, `butchery:raw_leg_of_lamb`, `sa_combat:burger`, `farmersdelight:bacon_and_eggs` → сковорода (не скрывать), жареные версии больших кусков (`butchery:cooked_chuck_steak` и т. п.), дубли пива/вина/виски из SA/SI → только лут.

## Блок 2. Вес и стаки (код, ядро для блоков 3–7)
1. Таблица `data/rpculinary/rpculinary/weights/*.json`: предмет → вес (г) и класс стака (порция 16, мелкое 32, стейк 8, цельное 4, большое 1). Для всех ингредиентов (решение «всё по весу»): овощи, мука, молоко и т. д.
2. Миксин на максимальный стак предмета по таблице (контейнеры не трогаем).
3. Нестакающиеся (большие куски, органы, тушки): вес и источник в NBT (`rpculinary:weight`, `rpculinary:source`), подсказка «Печень (корова), 1.2 кг».
   **Один предмет — два состояния:** `butchery:raw_wolf_meat` с весом в NBT — «Большой кусок волчатины, 4 кг», стак 1; без NBT — порция 250 г, стак 16 (стак считается по стаку, не по предмету). Доска режет первое во второе.
6. **Засолка/копчение/вяление — состоянием:** продукт + соль (бочка/миска) → NBT «солёное»; солёное в коптильне → «копчёное» (тёмная подкраска); сушка → «вяленое/сушёное». Для любого мяса, рыбы, сала; позже грибы и фрукты. Готовый `farmersdelight:smoked_ham` остаётся.
7. **Бульон** — `farmersdelight:bone_broth` как полуфабрикат (кости → кастрюля), а не только готовое блюдо.
4. Питание по весу: ккал/100 г × вес; `NutritionTable` берёт вес из NBT, если он есть. Пересчитать `nutrition/*.json` на «100 г» или «за штуку по весу».
5. Вес после готовки: жарка −25–35 %, варка −15 %, копчение −40 %, калории куска почти те же; в подсказке.

## Блок 3. Разделка туш: доп. разрезы и навык
1. Обработчик ПКМ по туше Butchery ножом: счётчик разрезов в данных мира по позиции блока; промежуточные разрезы выдают наши таблицы и отменяют событие; на «родных» разрезах пропускаем Butchery (модель меняется как раньше).
2. Планы разделки по видам — JSON (этапы, таблицы, вес туши, порог навыка 1–10 из §6).
3. Навык: потери в обрезки (60/30/10/0 % по отставанию от порога), опыт кулинарии за разрез (`RpCoreAPI.practice`).
4. Вес туши при переноске — замедление по реальному весу (решение «по весу туши»).

## Блок 4. Доска: нарезка по весу
Большой кусок / стейк / тушка → порции, бекон, отбивные, филе, кости, обрезки — по весу из NBT; порог навыка на 1 ниже туши; потери в обрезки; опыт. Сначала разобрать API доски FD (событие или своя обработка ПКМ).

## Блок 5. Фарш, сосиски, смешанный фарш, подкраска
1. Мясорубка F&C: любое сырое мясо → фарш (по цвету источника — 3 предмета, §6), обрезки ×2 → 1, потери 5–15 % в обрезки.
2. Мясорубка Butchery: сосиски/колбасы из фарша/обрезков + кишки → связка (4 порции); жареная связка + салат → 4 × `brewery:sausage`.
3. Смешанный фарш (вариант А): миска F&C — фарши разного вида → «Фарш (говядина, свинина)», состав в NBT, калории по долям, цвет средний.
4. Подкраска: общие формы (кусок мяса, фарш, обрезки) с источником в NBT — цвет слоя; модели чужих предметов переопределить с `tintindex` (наши ресурсы).

## Блок 6. Мешки и ящики с продуктами
F&C bags, Vinery bags, FD crates, Quark crates/sacks: стак 1, вместимость по весу (картофель ~25 кг); ПКМ продуктом — положить, ПКМ мешком — достать; поставленный блок: содержимое в данных мира по позиции, ПКМ рукой — достать, ломается с содержимым в NBT; пустой мешок/ящик — тот же предмет с нулём внутри, крафт из ткани/досок (не из 9 продуктов).

## Блок 7. Качество только у финальных блюд (сессия culinary-quality)
Полуфабрикаты — без качества (тег `rpculinary:no_quality`: фарш, тесто, сырая котлета, нарезка, сырая пицца, сыр); тепловая обработка — полное качество с подгоранием; холодные финальные блюда (салат, сэндвич, бургер) — качество без подгорания, худшее — «обычное». Состав блюда и стадию держать в одном NBT.
